# HagiTask - Agent Configuration

## Root Configuration

Inherits the monorepo rules from `/AGENTS.md`. This repository is the source of truth for preset-task schemas and shipped preset packages.

## Overview and Architecture

- `schemas/task-preset-plugin/` contains contracts for package manifests, panels, commands, prompts, locales, and store pages.
- `presets/<presetTaskId>/` contains loader-compatible shipped packages.
- Community packages belong in `hagitask-community-packages`; runtime copies under `hagicode-core` are transitional.
- Publication schemas and catalogs are generated by `hagitask-site`; do not author generated catalog output here.
- `schemas/` also holds the `community-index-v1` and `community-task-detail-v1` publication schemas shipped in the npm package.
- `src/` is the `@hagicode/hagitask` npm CLI/validation API (`cli.ts`, `commands/` for `validate` and `new`, `validation/`, `templates/`); `test/*.test.mjs` run against the built `dist/`. `scripts/validate.py` is an older standalone preset validator.

## Commands and Testing

Run from `repos/hagitask/`:

```bash
npm install
npm run validate
npm test
```

Node.js 24+ is required. `npx hagitask validate .` / `hagitask new <name>` are the CLI entry points; `npm run validate` builds first and validates this repository. `npm-publish.yml` publishes dev/release npm versions after `npm test`; `dist/` is build output.

Validate authored package files against the matching schema. Keep `$schema` references intact and run the relevant tests after schema or package changes.

## Conventions

- Keep the directory name, `manifest.json.taskPresetId`, and package references consistent.
- Preserve the shared package layout and both supported locale bundles. A shipped preset has `manifest.json`, `backend/` (`task-preset.json`, `prompts.json`, `templates/<locale>/system.md` + `user.hbs`), `frontend/panel.json` (plus optional `frontend/commands.json` with prompts in `backend/templates/<locale>/commands/`), `locales/<locale>.json` (en-US, zh-CN), and `store-page/index.<locale>.md`.
- Prompt template edits (`system.md`, `user.hbs`) must be mirrored in both `en-US` and `zh-CN` templates in the same change.
- `omitNonInteractiveHints` is a host-supplied system prompt input that only gates the run-mode wording; declare it in `backend/prompts.json` if a template uses it, but never in panels, `inputBindings` or create requests (see `README.md`).
- Put reusable package source here only when it is a shipped preset; public community tasks belong in the community repository.

## Deployment and Integration

The site consumes community packages from a pinned commit and publishes catalogs, details, schemas, and archives. Schema changes can affect `hagitask-community-packages`, `hagitask-contrib`, `hagitask-site`, `hagicode-core`, and `web`; check those consumers before changing a contract. Until the preset loading cutover is complete, keep the backend runtime copy synchronized when a shipped preset changes.
